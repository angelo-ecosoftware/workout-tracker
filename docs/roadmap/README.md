even when a plan is completed so decisions and historical context remain
available.

## Safe documentation rules

1. Do not delete planning documents during refactors.
2. Do not rename files without checking and updating all references.
3. Keep one active checkbox for each task in `TODO.md`.
4. Keep detailed requirements in supporting plans.
5. Mark completed work with its test and commit reference.
6. Archive only after the information has been linked and preserved.
